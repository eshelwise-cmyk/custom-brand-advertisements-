# Style Lock Skill

## Goal

Convert a curated visual direction into a reusable style contract that can be applied consistently to new advertising scenes.

## Required lock

Capture:

- style reference identifier or equivalent;
- style strength;
- stylization level;
- image-reference rules;
- aspect-ratio defaults;
- composition rules;
- color behavior;
- texture/material behavior;
- lighting behavior;
- subject treatment;
- negative-space rules;
- elements to avoid.

## Lock procedure

1. Name the direction.
2. Save the exact provider settings.
3. Test the lock against at least three different scenes.
4. Compare the outputs to the approved reference set.
5. Record known failure cases.
6. Mark the lock `approved` only when it is repeatable.

## Change control

A locked style is the baseline for a campaign. New references may be tested, but changes to the locked style should create a new version instead of silently changing the existing one.
