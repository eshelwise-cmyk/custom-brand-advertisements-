# Source Notes and Attribution

## Primary source

This repository was built from a transcript supplied by the repository owner. The transcript describes a workflow presented in a video for creating distinctive, repeatable brand imagery and using it in social content and advertising.

Source: user-supplied video transcript, provided to this project on 2026-08-11.

## Source-derived workflow

The transcript describes these main stages:

1. Start with brand context, including audience pains, desires, offers, psychographics, and existing brand intelligence.
2. Use a reusable skill to mine audience context into image scenes.
3. Explore visual styles by generating the same scene with randomized style references.
4. Curate styles using human judgment rather than accepting every generated result.
5. Test a selected style reference across multiple scenes.
6. Tune style strength and overall stylization.
7. Optionally combine multiple style references.
8. Test image references and composition, including negative space for later copy.
9. Lock the selected style as a reusable triplet of style reference, style weight, and stylization settings.
10. Batch concepts and variations, including prompt-level variation syntax.
11. Update the brand intelligence with an image doctrine or equivalent locked style specification.
12. Build and download a reusable image bank for future social content, ads, websites, posters, and related brand assets.
